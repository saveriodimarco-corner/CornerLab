# The Odds API integration

This sprint adds a provider layer for The Odds API without changing the research, prediction, or confidence logic.

- Historical odds require a paid plan and are not executed in this sprint.
- Current coverage must be tested with the free/current API before any purchase decision.
- No ROI claim is valid until real closing corner odds are imported and matched to verified fixtures.
- Additional-market coverage may vary by bookmaker and event.
