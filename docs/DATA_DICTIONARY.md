# Data Dictionary

The research dataset contains one row per match with raw match fields and research features generated by the existing feature-store pipeline.

## fixture_id
- Type: int64
- Description: Unique identifier for each fixture.

## date
- Type: object
- Description: Match date in ISO format.

## season
- Type: object
- Description: Season label.

## competition
- Type: object
- Description: Competition label.

## home_team
- Type: object
- Description: Home team name.

## away_team
- Type: object
- Description: Away team name.

## home_goals
- Type: int64
- Description: Home goals scored.

## away_goals
- Type: int64
- Description: Away goals scored.

## home_corners
- Type: int64
- Description: Home team corner count.

## away_corners
- Type: int64
- Description: Away team corner count.

## total_corners
- Type: int64
- Description: Combined corner count.

## source
- Type: object
- Description: Data provider source.

## import_date
- Type: object
- Description: Import timestamp.

## row_hash
- Type: object
- Description: Deterministic hash of the row payload.
